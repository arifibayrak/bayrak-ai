## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser (LivePeriodPoller) → Next.js RSC route | Polling triggers RSC re-render via router.refresh(); same auth-boundary as the initial page load (cookie-based session). |

| Rendered photoUrl link → external Vercel Blob | photo_url is a Vercel Blob URL stored in submissions; opens in target="_blank" with rel="noopener noreferrer" to prevent reverse-tabnabbing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04-XSS | Tampering | LineSubmissionsPanel renders workerName + notes | mitigate | React auto-escapes string content. No dangerouslySetInnerHTML. notes is rendered as plain text inside a TableCell. |
| T-12-04-TAB | Tampering | photo_url anchor opens in new tab | mitigate | target="_blank" paired with rel="noopener noreferrer" prevents the opened tab from accessing window.opener (reverse tabnabbing). |
| T-12-04-LEAK | Information Disclosure | LineSubmissionsPanel exposes submission detail to office user | accept | Office engineers have full read access to their tenant's submissions via Phase 5/8 surfaces; this panel adds no new disclosure surface. tenant-scoped getLineSubmissions matches Phase 8 V4 ASVS pattern. |
| T-12-04-POLL | Denial of Service | LivePeriodPoller fires 30s polls forever | mitigate | useEffect cleanup clears setInterval on unmount/disable; mount gated by status === 'draft' so finalized pages do not poll; Pitfall 6 React 19 strict-mode pattern verified by the test 9 assertion. |
| T-12-04-IDOR | Information Disclosure | LineSubmissionsPanel called with arbitrary periodLineId | mitigate | getLineSubmissions in src/actions/hakedis.ts is auth-guarded + tenant-scoped (Plan 03 Task 1 + RESEARCH §Example 4). A malicious client cannot read cross-tenant rows. |
| T-12-04-A11Y | (not STRIDE; a11y) | LivePeriodPoller sr-only label | accept | sr-only role="status" aria-live="polite" announces "auto-refreshing every 30 seconds" once per mount to screen readers. No visual disruption. |
