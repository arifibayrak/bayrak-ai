```typescript
async function getTxDb() {
  const { Pool, neonConfig } = await import('@neondatabase/serverless');
  const { drizzle } = await import('drizzle-orm/neon-serverless');
  try {
    // eslint-disable-next-line @typescript-eslint/no-require-imports
    const ws = require('ws') as { default?: unknown } | unknown;
    // eslint-disable-next-line @typescript-eslint/no-explicit-any
    neonConfig.webSocketConstructor = (ws as any).default ?? ws;
  } catch { /* ws not available — native WebSocket fallback */ }
  const pool = new Pool({ connectionString: process.env.DATABASE_URL! });
  return drizzle(pool);
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| confirm:submit callback → submissions insert | a possibly-replayed confirm must not create a second submission |
| in-memory captured data → DB row | the persisted row must carry tenant_id and the dedup natural key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | double-confirm inserting two submissions | mitigate | DB-level `submissions_flow_id_unique` + `.onConflictDoNothing()` on insert (D-13 Guard 2) — proven by the mandatory SC4 test (Task 3, Pitfall 7) |
| T-02-02 | Tampering | replayed confirm update_id | mitigate | processed_updates dedup middleware (Plan 04 Guard 1) fences the replay before the handler; SC4 test exercises both guards together (Task 3) |
| T-02-16 | Tampering | partial write (submission inserted, state not cleared, or vice versa) | mitigate | insert + state delete run in ONE getTxDb transaction (Task 2) — neon-serverless Pool, since neon-http cannot do transactions (Pitfall 2); rollback on failure |
| T-02-17 | Spoofing | confirm without a complete payload | mitigate | confirm re-loads state from DB and inserts only NOT-NULL required fields; missing photoUrl/projectId/boqItemId/quantity would violate NOT NULL constraints and roll back the transaction |
| T-02-SC | Tampering | npm installs | accept | No installs this phase |
</threat_model>
