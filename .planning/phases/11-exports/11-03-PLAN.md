## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → GET /api/exports/performance | unauthenticated request crosses here — auth() guard mandatory |
| query string → SQL filters | from/to/project flow into getPortfolioPeople filters |
| Postgres rows → Excel cells | money strings + percentages flow into ExcelJS cell values |
| logOfficeActivity metadata | workerCount + auditorCount + filename written to office_activity_log |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-AUTH | Spoofing | GET /api/exports/performance | mitigate | `auth()` first statement; 401 JSON; D-114 + SC5 enforcement. |
| T-11-03-IDOR | Information Disclosure | tenant scope | mitigate | `getPortfolioPeople` is tenant-scoped (lines 1101-1103 of analytics.ts) — fetches inside `getDefaultTenantId()` bound scope; route handler does not inline SQL. |
| T-11-03-FLOAT | Tampering | money precision in Excel cells | mitigate | D-116 — money/percentage strings flow into cells directly; numFmt applied at column level; no `parseFloat` in buildPerformanceSummary. |
| T-11-03-FILENAME | Tampering | filename injection via project name | mitigate | `toSlug` normalisation before Content-Disposition (Plan 11-01b). |
| T-11-03-OE-LEAK | Information Disclosure | Office Engineer activity in workbook | mitigate | D-110 — buildPerformanceSummary creates exactly 2 sheets, NO third sheet for Office Engineers. Code-level enforcement (no OE data ever fetched by this route). |
| T-11-03-DOS | Denial of Service | unbounded portfolio export | accept | getPortfolioPeople has no internal limit but is bounded by tenant assignment count — single-tenant MVP, acceptable. |
| T-11-03-FORMULA | Tampering | ExcelJS formula injection on displayName (CVE-2014-3524) | mitigate | All user-content string cells (worker displayName + auditor displayName) wrapped in `sanitizeExcelCell()` from Plan 11-01b. No new tenant boundary. WARNING 4 fix is structurally safe. |
