## Surface Specifications

### Surface 1: Exports Hub Page (`/dashboard/(admin)/exports`)

Replaces the Phase-8 coming-soon stub. Pattern: same as `hakedis/page.tsx` (heading row + content below).

**Layout:**
```
<div class="space-y-6">
  ── Heading row (flex justify-between items-center)
     Left: <h1 class="text-xl font-semibold">Dışa Aktarma / Exports</h1>
           <p class="text-sm text-muted-foreground">{subtitle}</p>
  ── Global FilterBar (date-range + project; existing component, wrapped in <Suspense>)
  ── Three trigger sections in a <div class="space-y-6">:
     1. Gönderim Listesi / Submission Ledger trigger card
     2. Performans Özeti / Performance Summary trigger card
     3. Hakkediş Dosyaları / Hakkediş Files (period picker + download actions)
```

**Trigger cards (surfaces 1a and 1b — Submission Ledger, Performance Summary):**

Each is a shadcn `<Card>` with:
- `<CardHeader>`: section icon (Lucide `FileSpreadsheet`) + section label (`text-sm text-muted-foreground`)
- `<CardContent>`: active filter summary (project name + date range as `text-sm` chip) + primary download button
- Button: `variant="default" size="sm"` — label "Excel İndir / Download Excel" with `Download` Lucide icon (`h-4 w-4 mr-1`)
- Loading state: button shows spinner (`Loader2` icon with `animate-spin`) and is `disabled`
- Empty/no-data state: instead of the download button, show `<p class="text-sm text-muted-foreground">` with the no-data copy (see Copywriting) — no button rendered

**Period picker (surface 1c — Hakkediş Dosyaları):**

A `<Card>` containing:
- Section heading: "Hakkediş Dosyaları / Hakkediş Files" (`text-sm font-semibold` inside CardHeader)
- A shadcn `<Table>` listing finalized/submitted/paid periods (status != 'draft')
  - Columns: Dönem / Period, Bitiş Tarihi / End Date, Para Birimi / Currency, Durum / Status, Net Ödeme / Net Payable, İndir / Download
  - "Durum" column: reuse `<HakedisStatusBadge>` from Phase 10
  - "Net Ödeme" column: `text-right tabular-nums text-sm`, formatted via `formatMoney` + `formatMoneyAmount`
  - "İndir" column: two small buttons side-by-side — `variant="outline" size="sm"`:
    - "Excel" with `FileSpreadsheet` icon (`h-4 w-4`, `aria-label="Excel İndir"`)
    - "PDF" with `FileText` icon (`h-4 w-4`, `aria-label="PDF İndir"`)
  - Each button is an `<a href="/api/exports/hakedis/{id}/..." download>` wrapped in a Button (or `asChild` pattern)
- Empty state when no finalized periods exist: `<div class="flex flex-col items-center gap-3 py-12 text-center">` with `FileX` icon + empty state copy + link to `/dashboard/hakedis`

### Surface 2: Period Detail Page Extension (`PeriodDetailControls.tsx`)

**Additive only** — two new buttons appended to the existing `<div class="flex items-center gap-2">` control row. They appear when `status !== 'draft'` (finalized, submitted, or paid).

```tsx
{/* Shown when status !== 'draft' */}
{status !== 'draft' && (
  <>
    <a href={`/api/exports/hakedis/${periodId}`} download>
      <Button variant="outline" size="sm" aria-label={t('detail.export_excel')}>
        <FileSpreadsheet className="h-4 w-4 mr-1" aria-hidden="true" />
        {t('detail.export_excel')}
      </Button>
    </a>
    <a href={`/api/exports/hakedis/${periodId}/pdf`} download>
      <Button variant="outline" size="sm" aria-label={t('detail.download_pdf')}>
        <FileText className="h-4 w-4 mr-1" aria-hidden="true" />
        {t('detail.download_pdf')}
      </Button>
    </a>
  </>
)}
```

Button labels (TR primary / EN secondary, joined): "Excel'e Aktar / Export Excel" and "PDF İndir / Download PDF".

**Loading state:** Each button gains `disabled` + `Loader2 animate-spin` icon during the download fetch (if implemented as a click handler instead of bare `<a>` — see Interaction Contracts).

**Draft guard:** Buttons are REMOVED (not disabled) for `status === 'draft'` — consistent with the existing `PeriodDetailControls` state-gated removal pattern (D-96).

---

### Surface 3: Download Trigger Interaction Contract

All download triggers follow this pattern:

1. **Preferred pattern:** `<a href="/api/exports/..." download>` wrapping a shadcn `<Button>`. The browser handles the request natively. No JS loading state needed.
2. **If fetch-controlled (for error handling):** Click handler calls `fetch('/api/exports/...')`, sets `downloading` state, and on success creates a blob URL + triggers `<a>` click programmatically. On error shows inline `<Alert variant="destructive">`.
3. **Error presentation:** `<Alert variant="destructive"><AlertDescription>{error_copy}</AlertDescription></Alert>` — same pattern as `PeriodDetailControls` error state. Position: above the trigger button.
4. **Accessibility:** Every icon-only or icon+text button must have an explicit `aria-label` in TR ("Excel İndir", "PDF İndir"). Icon elements carry `aria-hidden="true"`.
5. **Auth guard:** The route handler returns HTTP 401 on no session. Client shows the generic "unauthorized" error copy (see Copywriting). No redirect — these are binary content endpoints.

## Implementation Constraints (Carry into Plan)

1. **`export const dynamic = 'force-dynamic'`** on `exports/page.tsx` — financial data must never be statically cached (v2.0 lock).
2. **`auth()` first statement** in `exports/page.tsx`; redirect to `/auth/signin` on null session (matches hakedis/page.tsx).
3. **FilterBar in `<Suspense>`** — `FilterBar` uses `useSearchParams()`, causing CSR bailout. Fallback: `<div class="h-9 w-full animate-pulse rounded-md bg-muted" />` (matches Phase-10 pattern).
4. **Period picker: status filter** — only `status != 'draft'` rows shown. Never surface draft periods in the Exports hub picker (D-107 immutability).
5. **Money display** — `formatMoney` / `formatMoneyAmount` from `src/lib/format-money.ts`; NEVER `parseFloat` on money strings (T-10-04-FLOAT).
6. **No eager PDF generation** — on-demand only (D-107). No Vercel Blob storage of PDFs.
7. **shadcn CLI** — `node_modules/.bin/shadcn add` (CLAUDE.md constraint — NOT `npx shadcn@latest`).
