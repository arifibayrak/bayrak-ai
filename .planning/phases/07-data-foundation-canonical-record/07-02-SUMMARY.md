## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Added --> statement-breakpoint markers to 0005_v2_indexes.sql**
- **Found during:** Task 2 — first migrate.ts run on 0005 failed with `cannot insert multiple commands into a prepared statement`
- **Issue:** neon-http driver sends each migration as a prepared statement; multiple CREATE INDEX statements without breakpoints sent as one batch → PG error 42601
- **Fix:** Added `-->statement-breakpoint` marker between each CREATE INDEX statement (same pattern as drizzle-kit generated files)
- **Files modified:** src/db/migrations/0005_v2_indexes.sql
- **Commit:** fdb0209

**2. [Rule 2 - Missing functionality] Added 0005_v2_indexes entry to meta/_journal.json before first migrate.ts run**

- **Issue:** Hand-written migration files are only picked up by Drizzle migrate() if listed in the journal; 0005 was absent

- **Files modified:** src/db/migrations/meta/_journal.json
