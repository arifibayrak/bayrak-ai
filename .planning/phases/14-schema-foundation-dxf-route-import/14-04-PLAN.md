<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/dxf-upload | untrusted upload-token request |
| client → uploadDxf | untrusted projectId, blobUrl, CRS, layer |
| blobUrl → server fetch | server-side fetch of a caller-influenced URL (SSRF surface) |
| DXF content → parser | untrusted file content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-BLOB | Spoofing | /api/dxf-upload onBeforeGenerateToken | mitigate | auth() called inside onBeforeGenerateToken; throws on no session → unauth PUT impossible |
| T-14-AUTHZ | Information Disclosure | uploadDxf | mitigate | auth() guard first + CR-02 ownership check (project belongs to default tenant) before any write |
| T-14-SSRF | Elevation of Privilege | uploadDxf blobUrl fetch | mitigate | Validate blobUrl is https and host ends in .public.blob.vercel-storage.com before fetch |
| T-14-PARSE | Tampering | parseDxfToLineString | mitigate | parseSync wrapped in try/catch returning DXF_PARSE_FAILED; DXF content never executed |
| T-14-DOS | Denial of Service | Blob route + parser | mitigate | maximumSizeInBytes 50MB in token; vertex-count cap in parseDxfToLineString |
| T-14-VAL | Tampering | Turkey bbox gate | mitigate | COORDS_OUTSIDE_TURKEY rejects axis-swapped / out-of-country before validateLineStringGeoJSON and DB write |
| T-14-VERSION | Tampering | geometry_version increment | accept | MAX-subquery increment is safe for single-tenant MVP; multi-writer race accepted (Assumption A5) |
</threat_model>
