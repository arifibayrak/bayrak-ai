## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser file → client parse | untrusted DXF read client-side for layer list |
| client → uploadDxf / Blob | upload + write triggered from the browser |
| second Mapbox instance | preview map shares the page with the main MapView |
| route_source_documents read → client | history rows serialized and rendered as download links |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-PREVIEW | Tampering | SatellitePreviewModal | mitigate | No DB write until "Onayla — Kaydet"; İptal returns to layer-picker writing nothing (verified by DB check in checkpoint) |
| T-14-GHOSTMAP | Denial of Service | second Mapbox instance | mitigate | Conditional render `{open && <Modal/>}` unmounts the preview map on close (Pitfall 5); separate mapRef from MapView |

| T-14-XSS | Information Disclosure | Kaynak Belge download links | mitigate | blobUrl rendered as href with download + new tab; values originate from our own Blob store; no dangerouslySetInnerHTML |
| T-14-SRCDOC-READ | Information Disclosure | getRouteSourceDocuments | mitigate | auth() guard + default-tenant scope (mirrors getRoute); only the project's own history rows returned |
