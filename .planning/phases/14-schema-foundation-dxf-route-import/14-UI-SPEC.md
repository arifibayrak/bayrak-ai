# Phase 14 — UI Design Contract

> Visual and interaction contract for DXF route import, satellite preview confirmation,
> re-import warning, and the source-document (Kaynak Belge) section.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> **Scope note:** This phase adds UI surfaces inside the existing project RouteTab only.
> No new pages, no new sidebar items. All new surfaces inherit the Phase 13 brand spine.

| Property | Value |

## Spacing Scale

Declared values (multiples of 4 — 8-point grid via 4px base):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline chip padding |
| sm | 8px | Compact row spacing, badge internal padding |
| md | 16px | Card body default padding (`p-4`), form field gaps |
| lg | 24px | Between major card sections (`space-y-6`) |
| xl | 32px | Between upload section and map/source-doc area |
| 2xl | 48px | — (not used in this phase's surfaces) |
| 3xl | 64px | — (not used in this phase's surfaces) |

Exceptions:

- Card Header and Footer use `p-3` (12px) per D-125 compact density (pre-existing BrandCard.Header/.Footer pattern).
- Map container height: 400px (fixed, matching existing MapView height in RouteTabClient).
- Preview modal map container height: 480px (slightly taller — the satellite confirmation is the primary safety-net action; extra vertical space for the route to be clearly visible).
- Touch targets on icon-only dialog close: minimum 44px per accessibility requirement.

> Source: BRAND.md D-125; BrandCard.tsx compound; RouteTabClient.tsx pattern.

## Surface Inventory

Four new surfaces within RouteTab. All are additive — no existing surface is removed.

### Surface 1: DXF Upload Flow (DxfUpload.tsx)

Sits below the existing GeoJSON RouteUpload section inside RouteTabClient. The two upload paths are presented as labeled sections (a separator + "veya CAD dosyası (DXF)" label), not tabs — keeping the proven GeoJSON path visually primary.

**States (in order):**

| State | What the Engineer Sees |
|-------|----------------------|
| `idle` | Drop zone with dashed `border-slate-200` border, "DXF dosyası seçin veya sürükleyin" label, `.dxf` accept filter, BrandButton outline "DXF Seç" |
| `parsing` | Skeleton loader + "Katmanlar ayrıştırılıyor…" inline text (Geist Sans 14px muted) |
| `layer-picker` | BrandCard listing all detected layers: layer name, entity count, geometry type chip; auto-highlighted row (amber-50 bg + BrandBadge "Önerilen") for AXIS/CL/CENTERLINE/MERKEZ matches; engineer must click a row to select it |
| `crs-select` | Select dropdown (shadcn Select) with 7 preset options listed with human-readable Turkish labels (see copywriting); defaults to last-used CRS from localStorage keyed by projectId, falling back to TUREF/TM30 |
| `previewing` | (advances to Surface 2 — satellite preview modal opens) |
| `saved` | BrandBadge variant="success" "Rota kaydedildi", coordinate count in Geist Mono |
| `error` | Inline error message in `text-destructive text-sm` below the drop zone, no toast |

**Interaction notes:**

- The CRS selector and layer picker appear in sequence: parse → layer-picker → CRS → confirm (triggers preview).
- "İleri" (Next) BrandButton outline advances from layer to CRS step; BrandButton primary "Önizle" triggers the preview modal.
- Last-used CRS remembered in `localStorage` with key `bayrak-dxf-crs-{projectId}` (client-side only; no Server Action call).
- SPLINE entity warning: if selected layer contains SPLINE entities, a BrandBadge variant="warning" + inline text appear above the "Önizle" button: "Bu katmanda SPLINE geometrisi var. AutoCAD'den LWPOLYLINE olarak dışa aktarmanız önerilir." Non-blocking — engineer can still proceed.
- Gap warning: if stitched polylines have a gap > configured threshold, inline warning: "Segmentler arasında boşluk tespit edildi. Rota doğru mu?" Non-blocking.

### Surface 2: Satellite Preview Confirmation Modal (highest-risk surface)

Triggered from "Önizle" in DxfUpload. Implemented as a shadcn Dialog (full-screen on mobile, max-w-3xl centered on desktop).

**Modal anatomy (top to bottom):**

1. **Header** (BrandCard.Header p-3): "Rota Önizlemesi — Koordinat Sistemi Doğrulama" in BrandHeading h3 (20px, weight 600). Sub-label: "Rotanın harita üzerinde doğru konumda göründüğünü doğrulayın." (14px, muted).
2. **Map area** (480px height): Mapbox satellite basemap (style: `mapbox://styles/mapbox/satellite-streets-v12`), temporary GeoJSON source with the reprojected route drawn as a 3px amber-500 line. Start marker: green circle (emerald-600, 12px diameter). End marker: red circle (red-600, 12px diameter). Both markers rendered as Mapbox Markers, not layers.
3. **Length readout** (below map, BrandCard.Body p-4): "Toplam uzunluk: **{N.NN} km**" — the N.NN value rendered in Geist Mono weight 500. If the length is implausibly short (< 0.1 km) or long (> 2000 km), a BrandBadge variant="warning" "Olağandışı uzunluk" appears inline.
4. **Selected metadata summary** (same BrandCard.Body, below length): two items in a `flex gap-4` row: "Koordinat sistemi: {CRS label}" and "Katman: {layer name}" — both 12px muted.
5. **Footer** (BrandCard.Footer p-3, flex justify-end gap-2): BrandButton ghost "İptal" | BrandButton primary "Onayla — Kaydet".

**Key interaction rules:**
- Until the modal map has finished loading (MapView `onLoad`), the "Onayla" button is `disabled` with a Skeleton placeholder in the map area.
- Clicking "İptal" closes the modal and returns to Surface 1 in the `layer-picker` state — no DB write occurs (D-04 / SC-02).
- Clicking "Onayla" calls `uploadDxf` Server Action, shows loading spinner on the button, and on success closes the modal and sets DxfUpload to `saved` state.
- On Server Action error, the modal stays open and an inline error message replaces the sub-label text in the header (12px, `text-destructive`). The "Onayla" button is re-enabled for retry.

### Surface 3: Re-import Warning (D-04)

Rendered as an inline warning section at the top of the satellite preview modal (Surface 2) — not a separate dialog — when the project already has approved submissions.

**Appearance:** A `bg-orange-50 border border-orange-200 rounded-md p-3` container above the map with:
- Icon: `TriangleAlert` (lucide, size-4, text-orange-600) + text "Bu projede **{N} onaylı kayıt** var." in 14px weight 400.
- Body text below: "Bu rota yeni bir geometri sürümü (v{N+1}) olarak kaydedilecek. Mevcut kayıtların kilometre değerleri değişmeyecek." in 12px muted.

This warning block appears only when `approvedSubmissionsCount > 0` — fetched as part of the `uploadDxf` pre-check or passed as a prop to the modal.

**Not a blocking confirmation:** The warning is informational. The engineer still clicks the single "Onayla — Kaydet" button. No separate "Evet, devam et" step is required for this phase (the satellite preview confirmation already forces a deliberate action).

### Surface 4: Route Metadata Card + Kaynak Belge Section (D-06)

Extends the existing metadata card in RouteTabClient (currently shows `coordinateCount` + `uploadedAt`). The extended card uses BrandCard composition.

**Metadata card additions (after existing fields):**

| Row | TR label | EN label | Value rendering |
|-----|----------|----------|----------------|
| Koordinat sistemi | CRS | Coordinate system | CRS human-readable label (e.g. "TUREF/TM30") in 14px weight 500 |
| Kaynak katman | Source layer | Layer | Layer name string, 14px weight 500 |
| Toplam uzunluk | Total length | Total length | "{N.NN} km" in Geist Mono weight 500 |
| Geometri sürümü | Geometry version | Geometry version | "v{N}" wrapped in BrandBadge variant="info" |

These rows appear only when `sourceCrs` / `sourceLayer` / `totalLengthM` are non-null (i.e., a DXF has been imported). GeoJSON-imported routes show only `coordinateCount` + `uploadedAt` as before.

**Kaynak Belge section (below metadata card):**

A separate BrandCard below the metadata card with:

- **BrandCard.Header**: "Kaynak Belge" label in BrandHeading h3 (20px weight 600) + a BrandButton outline sm "DXF İndir" linking to `sourceBlobUrl` (new tab, download attribute). Only shown when `sourceBlobUrl` is non-null.
- **BrandCard.Body**: PDF inline viewer area — rendered only when a PDF source document exists (`pdfBlobUrl` non-null). Uses react-pdf `<Document>` + `<Page>` in a `'use client'` component (`PdfViewer.tsx`) dynamically imported with `{ ssr: false }`. The viewer shows page 1 by default with prev/next navigation for multi-page PDFs. Width: 100% of the card body, height: auto (react-pdf's intrinsic height per page). If no PDF: a muted "PDF kaynak belgesi yüklenmemiş." empty state using BrandEmpty (icon: FileText size-6 slate-300, no CTA button).
- **BrandCard.Footer**: Version history list — rendered only when `priorSourceDocuments` array has entries. Shows prior DXF uploads as a `<ul>` of links: "v{N} — {date}" in 12px muted, each linking to the blob URL. Max 3 visible; if more, a "Tüm sürümleri göster" ghost link expands the list.

### Destructive Actions

| Action | TR Confirmation | EN Confirmation |
|--------|-----------------|-----------------|
| Re-import over existing route (no approved submissions) | No separate confirmation needed — satellite preview "Onayla — Kaydet" is the confirmation | Same |
| Re-import over existing route (has N approved submissions) | Warning in Surface 3 inside the satellite preview modal: "Bu projede {N} onaylı kayıt var. Yeni geometri sürümü (v{N+1}) kaydedilecek. Mevcut kayıtların kilometre değerleri değişmeyecek." | "{N} approved submissions exist. New geometry version (v{N+1}) will be saved. Existing chainage values will not change." |

Approach: The satellite preview "Onayla — Kaydet" button serves as the single confirmation for both the georeferencing (mandatory safety net) and the optional re-import versioning warning. No additional confirmation dialog is introduced — the inline warning in the modal is sufficient. This follows the "one deliberate action" UX principle.

## State Machine: DxfUpload.tsx

```
idle
  → (file selected) → parsing
parsing
  → (success, layers found) → layer-picker
  → (error) → idle (error shown)
layer-picker
  → (layer confirmed) → crs-select
crs-select
  → (CRS selected, "Önizle" clicked) → preview-open (modal opens)
  → (back) → layer-picker
preview-open
  → (map loaded) → preview-ready
  → ("İptal") → layer-picker
preview-ready
  → ("Onayla — Kaydet") → saving
  → ("İptal") → layer-picker
saving
  → (success) → saved
  → (error) → preview-ready (error inline in modal)
saved
  ← terminal (user can start fresh import via "Rotayı Değiştir" button in metadata card)
```

## Mapbox Integration Notes (for executor)

The satellite preview modal introduces a second Mapbox map instance on the same page as the existing MapView. To avoid token count / instance conflicts:

- The preview map must unmount when the Dialog closes (`destroyOnClose` or conditional render).
- Use `react-map-gl/mapbox` import (same as existing MapView.tsx).
- Satellite style: `mapbox://styles/mapbox/satellite-streets-v12` (includes labels — helpful for engineers to verify city/district names match expectations).
- The temporary GeoJSON source is added via `useEffect` after map load: `map.addSource('preview-route', {...})` + `map.addLayer({...})`. Remove on unmount.
- `fitBounds` to the route's bbox with 60px padding after source add (mirrors existing `mapRef.current.getMap().fitBounds(...)` pattern in MapView.tsx).
- The map must not render if `NEXT_PUBLIC_MAPBOX_TOKEN` is undefined — show a `BrandEmpty` error state instead.

## react-pdf Integration Notes (for executor)

Per STACK.md and the established pattern:

```tsx
// PdfViewer.tsx — 'use client'
import { Document, Page, pdfjs } from 'react-pdf';
import 'react-pdf/dist/Page/TextLayer.css';
import 'react-pdf/dist/Page/AnnotationLayer.css';

pdfjs.GlobalWorkerOptions.workerSrc = new URL(
  'pdfjs-dist/build/pdf.worker.min.mjs',
  import.meta.url,
).toString();
```

Parent RSC imports it as:
```tsx
const PdfViewer = dynamic(() => import('./PdfViewer'), { ssr: false });
```

The PDF viewer is constrained to the BrandCard.Body width (100%) with `height: auto`. It renders page 1 on mount. Prev/Next buttons are BrandButton ghost sm with ChevronLeft / ChevronRight lucide icons (size-4). Current page display: "1 / {total}" in 12px muted Geist Sans.
