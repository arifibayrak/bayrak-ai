## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-IV | Tampering | ?status=/?page= | mitigate | getSubmissions whitelists status (Plan 02 T-05-IV); KayitlarTab falls back to 'all' on invalid status and coerces page to a positive int (Task 1) |
| T-05-XSS | Tampering (XSS via photo URL) | thumbnail + lightbox | mitigate | photos render only via next/image (validated against remotePatterns, Plan 01 T-05-01); no raw <img src> with untrusted URL |
| T-05-TN | Tampering (reverse tabnabbing) | Google Maps external link | mitigate | external <a> uses rel="noopener noreferrer" + target="_blank" (Task 2) |
| T-05-AC | Information Disclosure | submissions rows | accept | getSubmissions is auth+tenant-scoped server-side (Plan 02 T-05-AC) |
</threat_model>
