| Boundary | Description |
|----------|-------------|
| client → server action | projectId, status filter, page/pageSize arrive from the client (URL params); untrusted |
| server action → PostGIS | geometry read via sql`` ST_AsGeoJSON; status/page interpolation risk |
| tenant data → response | every read must stay within the owning tenant/project (no cross-tenant leak) |

## STRIDE Threat Register

| T-05-AC | Information Disclosure | getSubmissions / getApprovedPoints / getRouteGeoJSON | mitigate | auth() guard on every action; reads scoped by projectId (tenant-scoped via projects); no raw tenant_id accepted from client (Task 1+2) |
