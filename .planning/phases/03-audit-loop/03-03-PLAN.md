## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-CB-01 | Tampering | callback_data forgery | mitigate | callback_data encodes WHICH submission (`audit:approve:<id>`), never WHO may act. Authorization is re-checked server-side against assignments on every tap (Plan 05, D-36). This plan only emits the data; it grants no permission. |
| T-3-CB-02 | Denial of Service | callback_data >64 bytes silently dropped by Telegram | mitigate | Keyboards carry only `audit:<action>:<submissionId>` (52 bytes); all other context derived from a DB lookup in the handler (RESEARCH Pitfall 5). AUDIT-02 byte-length test enforces it. |
| T-3-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages (RESEARCH.md Package Legitimacy Audit: none). |
