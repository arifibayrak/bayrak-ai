## Scope

Phase 16 UI is intentionally small. No new pages, no new tabs. Two net-new rendering surfaces mounted in existing views:

1. **`AiFlagCard`** — mounted inside `src/components/admin/SubmissionDetailView.tsx`. Renders only when `getSubmissionAiFlag` returns an `eval_passed = true` row; absent entirely otherwise.
2. **Amber strip indicator** — a small amber dot column added to `src/components/dashboard/ChainageTable.tsx` row cells that have at least one `eval_passed` AI flag on any submission in that bucket.

Both surfaces use brand primitives from `src/components/brand/`. No unbranded shadcn defaults on feature surfaces.

## Component Inventory

### `AiFlagCard` (new — `src/components/brand/AiFlagCard.tsx` or `src/components/admin/AiFlagCard.tsx`)

Placement: inside `src/components/admin/SubmissionDetailView.tsx`, below the location/photo fields, above the audit decision trail.

Visibility gate: rendered ONLY when `getSubmissionAiFlag(submissionId)` returns a non-null row with `eval_passed = true`. When absent, zero DOM — no placeholder, no skeleton, no empty card. This is a hard conditional render.

Visual structure (using brand primitives):

```
BrandCard (border-slate-200 shadow-none rounded-md)
  BrandCard.Header (p-3)
    BrandHeading size="h3"  → "AI Değerlendirmesi" (TR) / "AI Assessment" (EN)  [16px 600]
    Icon: <Bot size={16} className="text-slate-400" />   [lucide-react]
    Advisory label: BrandBadge variant="neutral" → "Tavsiye Niteliğinde" (TR) / "Advisory" (EN)
  BrandCard.Body (p-4)
    ── Per-signal rows (one per flag type present) ──
    [signal icon]  [anomaly description — Turkish — 14px 400 leading-[1.5]]
    [confidence badge: BrandBadge variant={success|warning|destructive}]
    [confidence score in Geist Mono 12px: e.g. "0.87"]
    ── Material suggestion (if present) ──
    Label: "Önerilen Sınıflandırma:" (TR) / "Suggested Classification:" (EN)  [12px 500]
    Value: material suggestion text  [14px 400]
```

Advisory framing is mandatory: the card MUST visually read as a non-blocking hint. Enforce via:
- `BrandBadge variant="neutral"` ("Tavsiye Niteliğinde") in the card header — always present
- No CTA button inside the card — zero approve/reject affordance
- Card border: `slate-200` (not amber/red — those would imply urgency or required action)
- Card background: white (same as all other detail-view cards) — no colour highlight

The five signal types (D-01) map to lucide icons:
| Signal | Icon | lucide name |
|--------|------|-------------|
| Photo ≠ claimed work | `ImageOff` | `image-off` |
| Photo quality | `Eye` | `eye` |
| Location second opinion | `MapPin` | `map-pin` |
| Notes → material suggestion | `FileText` | `file-text` |
| Duplicate/near-duplicate photo | `Copy` | `copy` |

All icon instances: `size={16}` (`size-4`), `className="text-slate-500"`.

### Amber strip indicator (modification to `ChainageTable.tsx`)

A new column added to the existing `ChainageTable` at the far-left or far-right of the row (planner to place consistently with existing column order).

Element: `<span className="inline-block size-2 rounded-full bg-amber-500" />` — 8px filled circle in `amber-500`. Visible only when the bucket has at least one `eval_passed = true` AI flag on any of its submission IDs.

Tooltip (on hover): `"Bu segmentte AI tavsiyesi var"` (TR) / `"AI advisory on this segment"` (EN). Use shadcn `Tooltip` (already in `src/components/ui/tooltip.tsx`).

When no flag: the column cell is empty — no placeholder dot, no outline dot. The absence of the amber dot means "no AI advisory."

## Copywriting Contract

All copy is bilingual. TR is primary (field staff / auditor language). EN is parity (office engineer toggle). Key `next-intl` namespace: `dashboard.admin.ai_flags`.

| Element | TR copy | EN copy |
|---------|---------|---------|
| AiFlagCard heading | "AI Değerlendirmesi" | "AI Assessment" |
| Advisory badge | "Tavsiye Niteliğinde" | "Advisory" |
| Material suggestion label | "Önerilen Sınıflandırma:" | "Suggested Classification:" |
| High confidence badge | "Yüksek Güven" | "High Confidence" |
| Medium confidence badge | "Orta Güven" | "Medium Confidence" |
| Low confidence badge | "Düşük Güven" | "Low Confidence" |
| Strip indicator tooltip | "Bu segmentte AI tavsiyesi var" | "AI advisory on this segment" |
| Absent state | *(no render — zero DOM)* | *(no render — zero DOM)* |
| Loading state | *(no loading state — AiFlagCard is server-rendered via RSC; data is fetched before render)* | *(same)* |

**Signal anomaly descriptions** are generated by the AI model in Turkish and stored in `submission_ai_flags.anomaly_description`. The UI renders these stored strings verbatim. The UI-SPEC does not define these dynamically-generated strings, only the surrounding chrome copy above.

**Error state:** If `getSubmissionAiFlag` throws, the error is caught silently — the AiFlagCard simply does not render. AI advisory failure must never surface an error UI on the submission detail page. Log server-side only.

**No destructive actions** in Phase 16. No confirmation dialogs required. AI flags are read-only advisory.

## Interaction Contract

### AiFlagCard

- **No interactivity inside the card.** Advisory text only. No buttons, no toggles, no collapse/expand in v4.0.
- **No loading spinner.** The card is fetched server-side (RSC). Either it renders with data or it does not render.
- **No empty state variant.** Absence = no render (see visibility gate above).

### Amber strip indicator

- **Hover only** interaction: Tooltip appears on hover (shadcn Tooltip, 300ms delay default). No click action — the indicator is informational; clicking the row itself already navigates to the submission detail where the AiFlagCard appears.
- **No animation.** Static dot, no pulse, no flash. The advisory nature requires calm presentation.

---

## Accessibility

- AiFlagCard: `<section aria-label="AI Değerlendirmesi">` wrapper. Each signal row uses `<dl><dt>` (signal type) + `<dd>` (description) semantic structure.
- Confidence badge: `aria-label="Güven skoru: {score} — {yüksek|orta|düşük}"` on the BrandBadge element.
- Amber dot indicator: `aria-hidden="true"` (purely visual; Tooltip provides the accessible label via `aria-describedby` on the parent row or cell).
- All lucide icons inside AiFlagCard: `aria-hidden="true"` (decorative; text carries meaning).
