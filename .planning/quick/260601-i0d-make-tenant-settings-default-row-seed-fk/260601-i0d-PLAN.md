# Quick Task 260601-i0d: FK-safe tenant_settings seed migration

## Objective

Migration `0007_v2_tenant_settings.sql` seeds the default-tenant `tenant_settings` row with an **unconditional** INSERT that has an FK to `tenants.id`. This succeeds on prod (default tenant exists) but **fails with an FK violation on any DB where the default tenant is absent** — the test branch DB (dynamic tenants, then truncated) and any fresh preview/branch DB. `0007` itself must NOT be edited (its drizzle migration hash is journaled on prod; editing breaks integrity). Add a NEW follow-up migration `0015` that re-seeds the row **conditionally** so it no-ops gracefully when the default tenant is absent and seeds when present.

This is a migration-portability / dev-experience fix, not a production data bug (`getTenantSettings` has a code-level default fallback; on prod the row already exists so the new migration is a no-op via `ON CONFLICT DO NOTHING`).

## Task 1: Add FK-safe conditional-seed migration 0015

**files:**
- `src/db/migrations/0015_v4_tenant_settings_seed_fk_safe.sql` (new)
- `src/db/migrations/meta/_journal.json` (append idx 15 entry)

**action:**
- Create `src/db/migrations/0015_v4_tenant_settings_seed_fk_safe.sql` containing exactly the portable conditional-insert pattern:
  ```sql
  -- Re-seed the default-tenant settings row FK-safely (portable to fresh/preview/test DBs).
  -- 0007 seeded this unconditionally with an FK to tenants.id, which violates on any DB
  -- where the default tenant is absent. This conditional insert no-ops when the default
  -- tenant does not exist and seeds when it does. On prod the row already exists, so
  -- ON CONFLICT DO NOTHING makes this a no-op there. Do NOT edit 0007 (hash is journaled).
  INSERT INTO "tenant_settings" (tenant_id, audit_sla_hours, rejection_rate_threshold, stalled_days)
  SELECT '00000000-0000-0000-0000-000000000001', 48, '0.3000', 7
  WHERE EXISTS (SELECT 1 FROM "tenants" WHERE id = '00000000-0000-0000-0000-000000000001')
  ON CONFLICT (tenant_id) DO NOTHING;
  ```

Keep the file valid JSON.
